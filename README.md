# 🤖 Novatech Robo AR Experience

An interactive Augmented Reality (AR) web application developed using MindAR, A-Frame, and WebAR technologies.

The project allows users to scan predefined image targets and experience interactive AR content such as:

- Animated 3D Robot Models
- Video-Based AR Content
- Image Tracking and Recognition
- Real-Time Multimedia Interaction

---

## 📌 Features

### 1. Animated 3D Robot Experience
- Scan the Novatech Robo image.
- A 3D animated robot appears in AR.
- The robot performs a dance animation in real time.

### 2. Video-Based AR Experience
- Scan specific target images.
- Corresponding videos are displayed and played directly on top of the detected image.

### 3. Multi-Target Tracking
- Supports multiple image targets within a single application.
- Different AR content can be linked to different images.

### 4. Web-Based AR
- No mobile application installation required.
- Runs directly in a web browser.
- Camera access enables real-time AR tracking.

## 🚀 How to Run

### Method 1: VS Code Live Server

1. Clone the repository

```bash
git clone <repository-url>
```

2. Open project in VS Code

3. Install Live Server Extension

4. Right Click

```text
index.html
```

5. Select

```text
Open with Live Server
```

6. Allow Camera Permission

7. Scan the target image

---

### Method 2: GitHub Pages

1. Push project to GitHub

2. Open Repository

3. Go to:

```text
Settings
→ Pages
```

4. Select:

```text
Deploy from Branch
```

5. Choose:

```text
main
/
root
```

6. Save

7. GitHub generates a public URL

Example:

```text
https://yourusername.github.io/novatech-robo-ar
```
